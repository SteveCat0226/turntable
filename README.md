# 命運轉盤 Fate Wheel

一個以深色與金色為主題的互動轉盤網頁。輸入猶豫不決的選項，讓轉盤幫你隨機選出答案。

直接進入轉盤：<https://stevecat0226.github.io/turntable/>

備用網站：<https://fate-wheel-eason.steelygala4.chatgpt.site>

目前網站為公開存取，任何人開啟網址即可使用，不需要登入 ChatGPT。

## 功能

- 自訂新增、刪除或清空選項，最多 30 個，每個最多 32 個字元。
- 至少 2 個選項即可轉動，每個選項擁有相同的抽中機率。
- 轉盤旋轉動畫與結果視窗，可選擇再次抽選。
- 提供「今天吃什麼」、「週末做什麼」、「幫我決定」三組範本；套用範本會取代目前選項。
- 可切換旋轉音效，以及啟用「抽中後移除」。
- 自動保存選項、移除設定及最近 20 筆抽選紀錄，畫面顯示最新 5 筆。
- 支援手機排版、鍵盤操作及系統減少動態效果設定。

## 技術

使用 HTML、CSS 與原生 JavaScript，沒有前端框架，也不需要安裝 npm 套件。

- Canvas API：繪製轉盤與動畫。
- Web Crypto API：產生隨機抽選結果。
- Web Audio API：產生音效。
- localStorage：在目前瀏覽器保存選項與抽選紀錄。
- Node.js 內建 HTTP 模組：提供本機預覽伺服器。

## 本機執行

建議使用近期版本的 Node.js 與 Chrome、Edge、Firefox 或 Safari。

1. 開啟終端機，切換到專案資料夾。Windows PowerShell 範例：

   ```powershell
   Set-Location -LiteralPath 'D:\智慧型系統設計\claude\fate-wheel'
   ```

2. 啟動預覽伺服器：

   ```powershell
   node server.mjs
   ```

3. 用瀏覽器開啟 <http://127.0.0.1:4173/>。
4. 結束預覽時，在終端機按下 `Ctrl+C`。

也可以直接用瀏覽器開啟 `dist/index.html`。建議透過本機伺服器操作，以取得較一致的瀏覽器 API 與資料保存行為。

若出現 `EADDRINUSE`，表示 4173 連接埠已被占用。請先停止先前的預覽，或修改 `server.mjs` 中的連接埠後重新啟動。

## 使用方式

1. 使用預設選項，或在輸入框輸入內容並按下「＋」新增。
2. 按選項旁的「×」可刪除該選項。
3. 視需要開啟音效或「抽中後移除」。
4. 按下「轉動命運」或轉盤中央的「轉動」。
5. 等待動畫停止，查看結果與抽選紀錄。

旋轉期間會暫停選項編輯，避免轉盤內容在抽選途中改變。啟用「抽中後移除」時，下一輪將使用剩餘選項；少於 2 個選項時需先新增選項。

## 修改內容

- 網站名稱與文字：編輯 `dist/index.html`。
- 配色、間距與手機版樣式：編輯 `dist/style.css`。
- 預設範本：修改 `dist/app.js` 中的 `presets`。
- 轉盤扇形顏色：修改 `dist/app.js` 中的 `palette`。
- 動畫時間：修改 `spin()` 內的 `duration`，單位為毫秒。

修改後重新整理瀏覽器即可看到結果，不需要建置。

## 資料與注意事項

- 資料保存在目前瀏覽器的 `localStorage`，不會同步至其他裝置或瀏覽器。
- 清除網站資料、使用無痕模式或改用其他網址時，保存的內容可能不同或消失。
- 每個選項列都是獨立抽選單位；若重複加入相同文字，該文字的總抽中機率會增加。
- 字型透過 Google Fonts 載入；離線時會改用系統字型。
- 本機伺服器僅監聽 `127.0.0.1`，供同一台電腦預覽使用。
- `dist/` 是可部署的靜態網站內容；`.openai/hosting.json` 綁定目前的 Sites 專案，建立另一個網站時應使用新的網站識別。
